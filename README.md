# PetShop Amigo Fiel - Fase 1

## Sobre o projeto
Sistema web para um petshop, desenvolvido como Fase 1 do Projeto da Disciplina.
Nesta etapa, o sistema contém apenas HTML estrutural, sem uso de CSS/Bootstrap
e sem funções em JavaScript (implementações previstas para a Fase 2).

## Objetivo e metas
**Objetivo:** construir a estrutura de páginas de um sistema web de e-commerce
para petshop, aplicando os conceitos de HTML semântico estudados nas Aulas 1 a 5
(estrutura de documento, tags semânticas, navegação, formulários e boas práticas
de organização de conteúdo).

**Metas específicas:**
- Criar cabeçalho (header) com identificação do petshop e navegação
- Criar corpo (body) com visualização de produtos (2 por categoria) e serviços
- Criar rodapé (footer) com informações de contato e navegação
- Organizar o conteúdo em páginas HTML separadas por categoria
- Publicar o projeto no GitHub e hospedá-lo via GitHub Pages

## Estrutura de arquivos
```
petshop/
├── index.html        (página inicial)
├── acessorios.html    (categoria: acessórios)
├── racoes.html        (categoria: rações não perecíveis)
├── higiene.html        (categoria: higiene e limpeza)
├── servicos.html      (banho e tosa, com/sem tele-busca)
└── README.md          (este arquivo)
```

## Funcionalidades da página web
- **Header:** presente em todas as páginas, contém o nome do petshop e um
  menu de navegação (`<nav>`) com links para todas as páginas do site.
- **index.html:** página de apresentação do petshop, com resumo das
  categorias de produtos e dos serviços oferecidos.
- **acessorios.html / racoes.html / higiene.html:** cada página exibe 2
  produtos da respectiva categoria, com imagem, descrição e valor.
- **servicos.html:** exibe os dois serviços de banho e tosa (com e sem
  tele-busca), com descrição e valor de cada um.
- **Footer:** presente em todas as páginas, contém informações de autoria,
  endereço, contato e novamente os links de navegação.

## Categorias de produtos
1. Acessórios (roupas, brinquedos, camas, etc.)
2. Rações não perecíveis
3. Higiene e limpeza (tapete higiênico, fraldas, etc.)

## Serviços oferecidos
- Banho e tosa sem tele-busca
- Banho e tosa com tele-busca

## Tecnologias utilizadas (Fase 1)
- HTML5 (sem CSS/Bootstrap, sem JavaScript)
